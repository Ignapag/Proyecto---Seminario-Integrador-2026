# Documentación

Seguí [AGENTS raíz](../AGENTS.md). Mantené el [índice](README.md) y enlaces relativos.

- Arquitectura describe implementación comprobada y enlaza entrypoints/contratos.
  Distinguir objetivos, excepciones y propuestas de lo que está activo.
- Código limpio reúne convenciones; desarrollo reúne comandos; flujo IA reúne
  skills y roles. Una regla tiene un dueño, los demás documentos lo enlazan.
- No inventar métricas, versiones remotas, decisiones históricas ni pruebas ejecutadas.
- Los informes de integración conservan su fecha y evidencia; no convertirlos en
  la única fuente del estado actual. El historial de Git no es contexto obligatorio.
- `DER.md` y `DICCIONARIO_DATOS.md` se generan desde SQL con sus scripts.
- Verificar enlaces, rutas, comandos y `git diff --check` en los documentos tocados.
  No levantar servicios ni ejecutar una suite de producto para una corrección de prosa.
- Planes y ADR solo si la tarea los necesita; no crear carpetas vacías ni informes
  de relleno. No incluir secretos ni datos de producción.
